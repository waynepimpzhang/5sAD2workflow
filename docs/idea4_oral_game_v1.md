# IDEA 4（改版）｜口腔消消樂 — 手遊化 5 秒 Parallax 創意

**專案**：好來 Activemint 超氟牙膏
**版位**：Parallax Scrolling，scroll 觸發 5 秒影片
**製作**：GPT-Image 2 生成首尾圖 → Kling AI 生成 5 秒動態 → AE 疊 UI/數字
**概念**：可消除 100 種以上口腔異味的牙膏
**核心轉譯**：把「消除 100 種氣味」變成一款**你正在玩的手遊**——關卡地圖就是你的口腔，敵人是食物氣味球，武器是牙刷＋牙膏。

---

## 一、世界觀設定（Art Direction）

### 場景：口腔內部「關卡地圖」
不做寫實醫學口腔（會噁心），改做**Q版糖果系關卡場**：
- **地板**：一排排排列整齊的**大白牙**當作地磚／平台，像消消樂棋盤，牙面帶琺瑯質光澤反光。
- **背景**：上方是柔和的粉色上顎穹頂（做成關卡天空，帶柔光暈），遠處霧化。
- **兩側**：口腔壁做成粉嫩的關卡邊框，帶輕微弧度，形成天然的 vignette 把視線收在中央。
- **前景**：幾顆帶景深模糊的氣味球飄過，做出手遊 UI 的層次感。
- **色調**：粉（口腔）＋ 白（牙齒）＋ 好來品牌綠 ＋ Activemint 薄荷藍白，冷暖對比乾淨不噁。
- **質感**：3D 手遊風（類 Candy Crush / 寶可夢大師 的塑膠感光澤），不寫實、不恐怖，父母帶小孩看也 OK。

### 敵人：食物氣味球（Odor Balls）
- 造型：Q 版球體，帶生氣的小眼睛與皺眉表情（可愛的壞蛋感），球體外圍浮動臭氣波紋（黃綠色）。
- 種類（建議 8 種主視覺，其餘用小球填數）：
  **蒜頭、洋蔥、咖啡、咖哩、燒肉、韭菜、臭豆腐、起司**
- 分級（做出遊戲層次）：
  - 小球（1 分）：一般食物味，一刷就破
  - 中球（3 分）：咖啡、咖哩，會左右閃避
  - **BOSS 球（大王）**：一顆巨型「蒜頭大王」，戴皇冠、體積是小球 5 倍，血條在畫面上方
- 被消除時：**啵**一聲爆成薄荷葉＋水花粒子，留下一顆小星星飄走。

### 武器：牙刷 ＋ 牙膏
- **牙刷**：Q 版加大刷頭，刷毛前端擠著一條**好來綠白薄荷膏體**，膏體會發光（像充能武器）。
- 牙膏管：關卡右下角當作「道具欄／彈藥」，管身用真實產品包裝（超氟 Activemint），這是**產品露出的合理位置**。
- 攻擊表現：刷頭橫掃時拖出一道**薄荷藍白光刃（Minty Sweep）**，光刃掃過範圍內氣味球連鎖爆開。

## 二、互動機制設計（三個方案，建議選 A）

### 【方案 A｜Scroll = 刷牙推進（建議）】★
**機制**：user 往下 scroll 的距離，直接等於牙刷在口腔裡「橫掃推進」的距離。滑得越多，刷得越深，消除越多。

| Scroll 進度 | 畫面 | HUD 變化 |
|---|---|---|
| 0% | 牙刷停在左側待命，滿場 100 顆氣味球 | 計數器 **100**、進度條 0%、COMBO 0 |
| 0→100% | 牙刷隨 scroll 由左往右橫掃，光刃掃過處氣味球連鎖爆破 | 計數器遞減、COMBO 數字暴衝、進度條填滿 |
| 100% | BOSS 蒜頭大王爆破，全場清空 | **0**、進度條 100%、**FRESH CLEAR!** |

**為什麼建議這案**
1. Scroll 是**線性連續**的，橫掃也是線性連續的，兩者 1:1 對應，手感最直覺。
2. 使用者會感覺「**是我刷掉的**」——參與感就是這個版位唯一的優勢。
3. 計數器可直接綁 scroll progress（`100 - progress*100`），影片只負責畫面，技術風險低。
4. 若使用者往上 scroll，數字回升、氣味球復原——**做出可逆的玩弄感**，很多人會來回滑，停留時間直接拉長。

### 【方案 B｜Scroll = 擠牙膏充能，滿了自動大招】
上半段 scroll：牙膏管被擠壓，膏體填滿刷頭的充能條（0→100%）。
充能滿的瞬間 → 觸發全屏大招：薄荷海嘯由上往下灌滿整個口腔，一次清空全場。
**優點**：爆發感最強、產品（牙膏管）是主角。**缺點**：前半段畫面較靜，可能流失。

### 【方案 C｜Scroll = 鏡頭下潛過關卡】
Scroll 帶著鏡頭從嘴唇一路往裡推進，像跑酷關卡，一路上牙刷自動清掉沿途氣味球，最後抵達喉部的 BOSS。
**優點**：Parallax 縱深感最漂亮（多層背景不同速度位移）。**缺點**：5 秒內要走完縱深，節奏很趕。

## 三、畫面 HUD／遊戲元素清單（讓畫面更豐富有趣）

疊在影片上的 UI 層（建議 AE 後製，不交給 Kling 生成，才會乾淨）：

**左上｜關卡資訊**
- `LEVEL 1 — 晚餐後的口腔`（可延伸 LEVEL 2 早餐後 / LEVEL 3 火鍋局，做成 campaign 系列）
- 三顆星星評價，隨消除數逐顆點亮

**右上｜異味計數器（主視覺數字）**
- 大字 `100` → `0`，下方小字 `ODOR REMAINING`
- 歸零瞬間變成綠色勾勾 ＋「**+12HR FRESH**」徽章

**中央上方｜BOSS 血條**
- 蒜頭大王出現時滑入，紅色血條被薄荷藍逐段扣光

**畫面中飛出的爆擊字（Damage Pop）**
- `+10`、`+50`、`NICE!`、`FRESH!`、`COMBO x12`、`PERFECT SWEEP!`
- 字體用圓潤有厚度的遊戲字（帶描邊＋落下陰影），好來綠與薄荷藍雙色

**底部｜刷牙進度條**
- 藍白薄荷條由左填滿，末端有小小的泡泡溢出
- 條上標記 `12HR` 里程碑

**右下｜道具欄**
- 好來超氟牙膏產品盒（真實包裝）＋ 一格 `Activemint™` 技能圖示，發光待命

**環境彩蛋（增加趣味）**
- 幾顆氣味球會**嚇到往後逃跑**，被光刃追上才爆
- 一顆小蒜頭球躲在牙縫裡發抖，最後被刷毛挑出來
- 被消除的球爆出**薄荷葉＋小水珠＋星星**三種粒子，不要只有一種
- 牙齒地磚被刷過後，表面**由暗黃轉為亮白**，並閃過一道 Sparkle 高光（清潔前後對比）
- 上顎穹頂在大招時透出薄荷藍光，像關卡通關的天光

## 六、製作備註（Kling / GPT-Image 分工）

1. **UI 與數字不要交給 Kling 生成**——AI 會把字寫壞。首尾圖生成「乾淨的口腔關卡＋角色＋牙刷」，HUD、計數器、爆擊字、血條、進度條**全部 AE 疊圖**，這樣才可控也才好做 scroll 連動。
2. **首尾圖必須同機位、同焦段、同光位**，只換三件事：氣味球有／無、牙齒暗／亮、空氣濁／清。Kling 首尾幀才不會漂。
3. Kling 生成時**避免要求牙刷做複雜 3D 旋轉**，維持「由左至右橫掃 ＋ 輕微鏡頭推進」，成功率最高。
4. 氣味球的表情建議在 GPT-Image 階段就固定好造型（做一版 character sheet），避免 Kling 中途變形。
5. 大招段（3.4-4.4s）若 Kling 難生成，可改由 AE 用粒子＋液體素材合成，銜接首尾幀。
6. 縱深建議切成 **4 層** 供 Parallax 位移：上顎背景 / 遠景牙齒＋霧 / 主棋盤氣味球 / 前景飛過的球與粒子。

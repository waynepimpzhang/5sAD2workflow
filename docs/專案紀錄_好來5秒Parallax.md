# 第一部分｜創意發想

## 1-1 起點條件

**TA 設定（客戶給定）**
- 有家庭的父母
- 在意口腔異味的上班族

**溝通概念（客戶給定）**
- 可消除 100 種以上口腔異味的牙膏

**素材依據**
好來 KV_20260430 — 睡前親子共讀場景，父親口中飄出薄荷葉，右側三顆食物方塊頭（黑胡椒、炸物、燒肉）示意 100 種食物氣味。

## 1-2 INSIGHT 推導

從「口氣差」這個功能性痛點，往上找一層社交層面的真實感受：

> **口氣比人先到。你還沒開口，它已經替你決定了別人退開幾公分。**

異味的殺傷力不在自己聞到，而在**對方的那個微小反應** —— 側個頭、退半步、把臉轉開。
消費者真正想買的不是清新，是**可以毫不猶豫靠近的權利**。
這正好接住 KV 主標「口氣清新 關係更靠近」，把抽象的「靠近」變成可被 scroll 觸發的物理位移。

**分眾延伸**
- 父母線：睡前是一天裡最靠近孩子的時刻，卻也是嘴裡累積了三餐加宵夜的時刻。「孩子不會客氣，他們躲的不是你，是你昨天吃的那一鍋。」
- 上班族線：遮嘴講話、講話偏 15 度、開會前狂嚼口香糖 —— **遮的不是嘴，是自信**。

**為什麼「100 種」值得被視覺化**
「100 種」是抽象的數字宣稱，但可視化成「100 個具體的食物」就變成畫面資產。
KV 已經做了一半（食物方塊頭），影片要做的是把「100」**從畫面上清掉** ——
scroll 的動作等於清除的動作，這是這個版位最天然的隱喻：**往下滑 = 沖刷 / 擠牙膏 / 抹去**。

## 1-3 版位機制的關鍵思考

Parallax scroll 版位跟一般 5 秒影片有兩個本質差異，整個創意都建立在這兩點上：

**一、使用者掌握停留時間。** 可以來回滑、可以停在任何一格。理解成本不是 1.5 秒的問題，
所以畫面裡可以放更多資訊（例如十種以上的食物），讓使用者停下來數 —— 那個「數得出來種類很多」
的體感，比任何文案都更能支撐「100 種」。

**二、遊戲感不靠靜態畫面證明，靠「我滑，畫面就有反應」證明。**
scroll 進度直接對應清除進度，因果關係本身就是說服力。

## 1-5 收斂邏輯

最後執行的兩支，是從六案中挑出**策略互補**的兩條路：

**IDEA 1（食物頭崩解 × 手放下來的混血）** 走**真實情境 × 社交尷尬**。
優勢是理解成本趨近於零 —— 觀眾自己就有那個經驗，0.3 秒就懂。

**IDEA 4（100 顆氣味歸零 → 遊戲化改版）** 走**機制轉譯 × 互動獎勵**。
優勢是把「100 種」從一句宣稱變成一個可數、可玩、有回饋的體驗。

兩支共用同一個 insight，但一支訴諸共鳴、一支訴諸參與。

# 第二部分｜成品 A：辦公室臭豆腐頭

## 2-1 廣告概念

**垂直剖面裡的一場自我修正。**

三個定格剛好是一棟辦公大樓的三層：**問題在樓上、解法在樓下、結果再下一層。**
攝影機像剖面圖一樣直直往下穿 —— 使用者往下滑的動作本身，就是把問題解決掉的動作。

嫌棄的戲全部交給兩位女同事，男主全程不知情；喜劇的殺傷力放在那塊**完全無表情的臭豆腐方塊**上，
它越理直氣壯越好笑。最後不靠台詞，只靠 SHOT 1 與 SHOT 3 的**同機位前後對照**，
以及兩位同事**身體傾向的距離變化**，把「口氣清新 關係更靠近」演出來。

## 2-2 TA

**主打：在意口腔異味的上班族**（25–45 歲，辦公室工作者）

場景設定在會議室與辦公大樓廁所，痛點是「開會時同事的反應」，
解法發生在午休的公司廁所 —— 全部落在上班族的日常動線裡。

**STEP 3　GPT-Image 2 生成素材**

## 2-6 踩過的坑

**一、Blender 攝影機上下顛倒。**
`rot_x = −90°` 讓攝影機朝 −Y，但那個角度的 up 向量指向世界 −Z，整個畫面是倒的、人頭在下。
正確是 `rot_euler = (90°, 0°, 180°)` —— 先繞 X 轉 90° 讓 up 為 +Z，再繞 Z 轉 180° 才朝向 −Y。

**二、Easing 設了但沒生效。**
設定 `AUTO_CLAMPED` 之後**沒有呼叫 `fc.update()`**，handle 沒重算，實際跑出來是線性等速。
改用 `kp.interpolation='CUBIC'` ＋ `kp.easing='EASE_IN_OUT'` 並明確 update 才正確。

**三、焦段算錯造成魚眼。**
32mm 搭配 `sensor_fit = HORIZONTAL`、`sensor_width = 36mm`，9:16 的等效垂直 sensor 是
36 × (1280/720) = 64mm，垂直 FOV 是 `2 × atan(32/32) = 90°` —— 超廣角。改成 49mm（垂直 66.3°）。
**教訓：改 lens 一定要連帶重算房間淨高，否則天花板 band 會跑掉。**

**四、前景道具擋鏡頭。**
為了模仿 KV 底部的桌面雜物加了四個前景道具，但距離鏡頭只有 0.50–0.76m，
投影出去橫跨畫面 −63% 到 184%，變成擋住鏡頭的怪方塊。
**建立檢查流程：改完場景就把每個 mesh 的 bounding box 投影一次，列出距離鏡頭 1m 內的物件。**

**五、KV 是合成稿，實拍鏡頭無法重現。**
疊格線量測後三個獨立算法都指向同一結論：KV 的人物被放大過。
KV3 男主的頭佔畫面高度 17%、同時三人橫向排開、前面還有整張桌子 —— 反算鏡頭要在 1.3m 內，
但那距離塞不進一張桌子。最後採取的解法是**把角色等比放大 1.5 倍**去對畫面比例，
這正是合成稿實際在做的事，對 AI 生成沒有影響，它讀的是構圖。

**六、Kling 沒有照 video reference 跑運鏡。**
第一次生成出來是三個鎖死機位加兩個硬切，完全沒有攝影機移動。原因有三：
- Negative prompt 裡寫了 `camera tilt, camera pan, camera rotation, zoom, dolly in, dolly out`，
  垂直下降在模型內部很可能被歸類成 dolly，一邊要它動一邊禁止 dolly，自相矛盾
- 「三個定格點必須完全靜止」等否定句密度遠高於描述移動的句子，整支片被讀成靜態
- 用的是場景描述（「沒入樓板暗部」）而不是運鏡指令（「攝影機垂直向下移動」）

修正方向：negative prompt 移除所有運鏡類禁令，改成禁止 `static camera, locked-off camera,
hard cut, jump cut`；prompt 開頭就宣告「這是一顆連續運鏡的長鏡頭，全片沒有任何剪接點」。

# 第三部分｜成品 B：口氣怪物消消樂

> 檔案：`idea4.mp4`

## 3-1 廣告概念

**把清潔變成過關。**

核心快感不在畫面漂亮，而在**節拍** —— 每一隻小怪被消除都是一次獨立的、
聽得見也看得見的獎勵回饋，十四次連續的小獎勵疊加成一次通關的爽感。

因此消除的節奏必須是**離散的、可數的**，而不是一團模糊的特效掃過。
觀眾要能在心裡數出「一、二、三」，那個數數的動作本身，
就是「有效消除 100 種食物氣味」這句宣稱的體感證明。

關卡地圖就是你的口腔，敵人是食物氣味怪，武器是牙刷加牙膏。

## 3-2 TA

**雙軌通用，偏向年輕族群與親子共視**

遊戲化的表現形式降低了說教感，父母帶小孩看也 OK；
食物怪的造型（咖啡、泡麵、燒肉、蔥、蒜）覆蓋上班族的日常飲食，兩邊都接得住。

## 3-3 溝通了什麼

| 層次 | 內容 |
|---|---|
| 情緒鉤子 | 消消壞口氣 |
| 功能宣稱 | 有效消除 100 種食物氣味 |
| 機制展示 | 進度條填滿 ＋ 計數 1→14 ＋ 逐一清除的食物種類 |
| 產品露出 | 底部產品帶（超氟 Activemint） |

**這支的說服邏輯跟 A 不同**：A 靠情境共鳴，B 靠**可驗證的數量感**。
右上圓圈每清一隻就換一張食物圖，等於在不用文字的情況下，
把「食物氣味的種類很多」這件事演了十四次。

## 3-5 製作流程

**STEP 1　概念轉譯與世界觀設定**
不做寫實醫學口腔（會噁心），改做 Q 版糖果系關卡場：
**齒列 U 型弧當棋盤**、粉色上顎與嘴唇框住畫面、食物怪站在牙齒上。

**STEP 2　風格定調（A-01 STYLE MASTER）**
第一版失敗，第二版才對（見 3-6）。定調圖是後續所有資產的唯一參考圖。

**STEP 6　泡泡字（GPT-Image）**
`消消壞口氣` 與 `有效消除 100 種食物氣味`，日式泡泡 logo 字風格。

**STEP 7　AE 合成**
UI 動態、進度條填充、計數數字、圓圈換圖、字卡、產品帶。

## 3-6 踩過的坑

**一、第一版風格定調完全失敗。**
出來的是漂亮的 3D 概念插畫而不是遊戲畫面，三個問題：

- **敵人變成通用細菌／病毒球**，認不出是什麼食物。這不只不好認，還**打錯訊息** ——
  核准宣稱是「有效消除 100 種**食物氣味**」，畫細菌等於暗示抗菌訴求，是另一個宣稱層級，
  在台灣有法規意涵。修法：全部改成**食物本體加眼睛**，靠輪廓辨識，不靠顏色。
- **直線後退的方格棋盤讀起來像棉花糖**。修法：改用**齒列 U 型弧**，牙弓的馬蹄形是「嘴」
  最強的識別符號，而且天然有「一排一排」的結構，剛好對應牙刷從左掃到右。
- **prompt 寫成 "key art" 還主動要求前景景深模糊**，那是海報寫法。
  修法：改成 "game screenshot"、平打光、**景深一律關閉**、UI 直接畫進定調圖。

**造型判準（後續沿用）**：
> 每個角色去色之後只看黑色剪影，要在兩秒內認得出來是什麼。
> 認不出來就重做，不要靠顏色補救 —— 版位縮小顏色會糊，剪影不會。

**二、UI 第一版太扁平，跟 3D 遊戲畫面不搭。**
原因是為了讓去背乾淨，prompt 裡寫了 `thick soft dark outlines`、`no drop shadows`、
`no bloom`、`flat off-white` —— 把所有製造立體感的元素都拿掉了，
`thick dark outlines` 更直接觸發扁平貼紙風。

修法：拿掉扁平描邊，改成「倒角、凹陷內壁、環境遮蔽」，用形體本身製造邊界；
把元素從「圖形」改成「物件」（進度條是有立體壁面的塑膠凹槽、圓框是有管狀圓潤度的環）；
把陰影和光暈放回來，只禁止大範圍投射到背景的陰影；加上三分之四透視。

**三、GPT-Image 的透明背景是假的。**
改用**洋紅幕 `#FF00FF`** 而不是綠幕 —— 好來品牌綠 `#00A44F` 跟去背綠太接近，
Keylight 一拉會把 UI 的綠色邊框一起吃掉，發光邊緣還會出現綠邊。
UI 配色是綠、薄荷藍、金、白，完全不含洋紅，去背非常乾淨。

實務上這幾個元素都是簡單凸形，**在 Photoshop 手工切五分鐘就有完美 alpha**，
比拉 key 更乾淨 —— 也因此不必為了 keying 犧牲陰影和光暈。

**四、UI 動態不要交給 Kling。**
三個硬傷：
- **數字一定會壞。** `×7` 這種東西是 AI 影片模型最不擅長的，出來是扭曲的偽數字
- **圓圈換圖是離散事件，模型只會做連續變形。** 要的是硬切，會得到蒜頭融化成咖啡杯的糊狀過渡
- **最關鍵是同步。** UI 的唯一工作是對已生成好的影片做反應，
  Kling 看不到那支影片的逐幀時間點，沒辦法對齊

AE 做這三件事都是十分鐘的工：進度條是矩形遮罩動寬度、數字是 Slider 加
`Math.round()` 表達式、圓圈換圖是圖層硬切加縮放彈跳。

**進度條不要等速填**，要對齊實際清除節奏（`0.5s` 起跑 / `1.75s` 約 40% / `2.75s` 約 65% /
`4.25s` 滿格）。等速填會跟畫面對不上，那個不同步一眼就看得出來。

**五、繁體字泡泡字的劃數限制。**
原本文案「消消壞口氣」的「壞」有 19 劃，泡泡字的做法是把筆劃充氣加粗，
劃數越多充氣後越糊。參考的日文平假名筆劃少又都是曲線，天生適合這個處理，繁體字不是。
（成品最終仍採用「消消壞口氣」，但過程中曾評估改為筆劃更少的「口氣消消」作為備案。）

# 第四部分｜兩支的策略分工

| | A 辦公室臭豆腐頭 | B 口氣怪物消消樂 |
|---|---|---|
| 說服路徑 | 情境共鳴 | 可驗證的數量感 |
| 理解成本 | 極低（0.3 秒） | 中（需要建立世界觀） |
| TA 側重 | 上班族 | 雙軌／偏年輕與親子 |
| 情緒 | 社交尷尬 → 釋然 | 破壞快感 → 通關 |
| 主要宣稱載體 | 前後對照＋距離變化 | 計數器＋逐一清除 |
| Scroll 機制運用 | 垂直穿越＝往下滑 | 清除進度＝滑動進度 |
| 製作難度 | 高（真人一致性、運鏡） | 中（單一場景、單一機位） |
| 改版彈性 | 低（換場景要重拍全部） | 高（換食物種類即可） |

**建議投放策略**：A 作為主打、B 作為 always-on。
B 的美術與 UI 是一套可複用的系統，換敵人組合就能做出 `早餐後`、`火鍋局`、`熬夜加班`
等不同關卡，素材複用率高。

# 第五部分｜可複用的方法論

## 5-1 AI 影片製作的分工原則

| 工作 | 交給誰 | 為什麼 |
|---|---|---|
| 空間、運鏡、easing | Blender 白模 | 精確可控、可反覆修改、可量化驗證 |
| 材質、光線、角色、表演 | Kling / GPT-Image | AI 的強項 |
| 文字、數字、UI、進度條 | AE | AI 必壞，且無法與既有影片同步 |
| 產品包裝 | Photoshop 合成 | AI 畫不出正確的中文包裝 |
| 精確的幾何轉場 | AE | 垂直位移＋遮罩＋速度曲線，可控性高一個量級 |

## 5-2 GPT-Image 的實務規則

1. **先做風格定調圖**，之後每一張都把它當參考圖，並在 prompt 開頭寫
   `Match the exact art style, material finish, lighting and colour palette of the reference image.`
2. **風格描述要內嵌在每一個 prompt 裡**，光靠參考圖不夠。
3. **一律不生成文字**，中文與數字全部後製。
4. **透明背景是假的**，用洋紅幕 `#FF00FF`（避開品牌綠與綠幕衝突）。
5. **角色 sheet 只用來定案造型**，最終素材要單獨出圖才會一致。
6. **前後對照的兩張圖，後圖一定要以前圖為參考**，否則對不齊。

## 5-3 Kling 的實務規則

1. **Negative prompt 不能跟正面指令打架。** 要運鏡就不能在 negative 裡禁止 dolly / tilt。
2. **運鏡要用運鏡動詞**（攝影機垂直向下移動），不能用場景描述（沒入樓板暗部）代替。
3. **開頭就宣告全片的鏡頭邏輯**（「這是一顆連續運鏡的長鏡頭，沒有任何剪接點」）。
4. **Video reference 是否吃攝影機路徑需要實測**，官方定位偏角色／元素參考。
5. **離散事件（換圖、計數）不要交給它**，它只會做連續變形。

## 5-4 生成前的檢查清單

- [ ] 宣稱是否落在核准範圍內（食物氣味 vs 抗菌，是兩個層級）
- [ ] 角色去色後看剪影，兩秒內認得出來嗎
- [ ] 場景裡有沒有距離鏡頭 1m 內的物件（會擋鏡頭）
- [ ] 焦段改了嗎，改了就要重算空間尺寸
- [ ] 前後對照的兩張圖，構圖是否像素級對齊
- [ ] 畫面裡有沒有 AI 生成的文字（一律移除，後製補）
